🅰️ Angular · Senior path · EduCommerce

Lộ trình Angular Senior

Từ Classic (NgModule · RxJS · class Guard/Interceptor) tới Modern (Standalone · Signals) — bằng cách migrate chính app mình đã build, không build lại từ đầu.

🎯 Cách học

Mỗi bài: bài toán thật → mental model → experiment nhỏ chạy được → áp dụng vào project → edge case production → quiz → tự code → review kiểu PR. Không bài nào qua được nếu tiêu chí ✅ chưa đạt.

Project xuyên suốt: EduCommerce — nền tảng e-learning kiêm bán khoá học. Data giả lập qua MSW dùng bộ mock có sẵn trong mock-data/. Mỗi bài đóng góp một mẩu chạy được vào app này.

Môi trường: Angular 22.1.4 chạy chế độ NgModule (--no-standalone) trên Node v24.18.0. Angular 16 "classic" thật không chạy được trên Node 24 — chỗ nào Angular 22 đã khác v12–v16, bài học sẽ chỉ đích danh.
