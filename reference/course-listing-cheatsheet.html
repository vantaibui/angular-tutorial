1. combineLatest cần MỌI nguồn có giá trị

TypeScript 
const a$ = new BehaviorSubject('');  // ✅ có giá trị NGAY — combineLatest phát được từ đầu
const b$ = new Subject();          // ❌ chưa .next() thì combineLatest KHÔNG BAO GIỜ phát
combineLatest([a$, b$]).subscribe(...);
Dùng khicombineLatest nhiều nguồn1 state object + patch()

1 hành động → mấy emission?Mỗi .next() = 1 emission riêngpatch({a, b}) = 1 emission duy nhất

2. Debounce ĐÚNG CHỖ — trên nguồn thô, không trên state đã gộp

TypeScript 
private readonly searchInput$ = new Subject<string>();          // bàn phím thô
private readonly filterSubject = new BehaviorSubject<FilterState>({...}); // state đã gộp

searchInput$.pipe(debounceTime(300), distinctUntilChanged())
  .subscribe((search) => this.patchFilter({ search, page: 1 }));

// filterSubject KHÔNG debounce -> lần load đầu tiên không bị trễ 300ms vô lý
result$ = filterSubject.pipe(distinctUntilChanged(sameFilter), switchMap(fetch));
🔥 Đặt debounce trên state đã gộp → mọi lần vào trang đều trễ 300ms

debounceTime áp cho MỌI emission đi qua nó, kể cả emission khởi tạo lúc ngOnInit khôi phục filter từ URL — không riêng gì thao tác gõ phím.

4. Generics ở tầng component — TemplateRef + ngTemplateOutlet

TypeScript 
export class GenericListComponent<T> {  // KHÔNG ràng buộc gì — không đọc field nào của T
  @Input() items: T[] = [];
  @Input() itemTemplate!: TemplateRef<{ $implicit: T; index: number }>;
}
HTML 
<ng-container *ngTemplateOutlet="itemTemplate; context: { $implicit: item, index: i }"></ng-container>
-- Nơi dùng: <ng-template let-c let-i="index"> -- let-c nhận $implicit NGẦM ĐỊNH, field khác phải khai rõ tên.

5. forkJoin fail-fast — cách ly lỗi TRONG từng nhánh

TypeScript 
forkJoin({
  course: courseService.getById(id).pipe(catchError(() => of(null))),      // mỗi nhánh TỰ bắt lỗi
  reviews: courseService.getReviews(id).pipe(catchError(() => of([]))),
}).subscribe(...);
-- catchError NGOÀI forkJoin: chỉ bắt được sau khi forkJoin đã lỗi HOÀN TOÀN -- mất cả nhánh THÀNH CÔNG.
-- catchError TRONG từng nhánh: forkJoin không bao giờ thấy lỗi -- mỗi nhánh độc lập cách ly.
🔥 forkJoin thừa hưởng nguyên tắc Bài 01: 1 Observable lỗi = kết thúc

Không catchError trong nhánh nào lỗi → toàn bộ forkJoin lỗi, kể cả các nhánh khác ĐÃ thành công từ lâu.

6. Góc phỏng vấn

Câu hỏiTrả lời gọn
Khi nào dùng combineLatest, khi nào gộp 1 state object?combineLatest cho nguồn ĐỘC LẬP thật sự. Khi 1 thay đổi phải kéo theo thay đổi khác (atomic), dùng 1 BehaviorSubject<State> + patch() để tránh N emission cho 1 hành động.
Vì sao | async "an toàn" hơn .subscribe() thủ công ở app zoneless?AsyncPipe tự gọi markForCheck() mỗi lần Observable phát giá trị, và tự unsubscribe khi component huỷ — 2 việc bạn phải tự làm nếu subscribe thủ công.
Generics áp dụng cho Component thế nào?TemplateRef<Context> làm Input, dùng ngTemplateOutlet để "tiêm" cách hiển thị 1 item từ bên ngoài — component không cần biết hình dạng T.
forkJoin vs combineLatest vs zip?forkJoin: N Observable, lấy giá trị CUỐI CÙNG của mỗi cái, phát 1 lần khi TẤT CẢ complete (hợp cho HTTP). combineLatest: phát lại mỗi khi 1 nguồn đổi, dùng cho stream sống lâu dài. zip: ghép theo THỨ TỰ index, hiếm dùng hơn trong CRUD app.
